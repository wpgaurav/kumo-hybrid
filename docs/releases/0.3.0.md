# Kumo Hybrid 0.3.0 release

Published November 8, 2026.

- Product: https://gauravtiwari.org/product/kumo-hybrid/
- Demo: https://demo.gatilab.com/kumo-hybrid/
- GitHub release: https://github.com/wpgaurav/kumo-hybrid/releases/tag/v0.3.0

The free FluentCart product issues lifetime keys for unlimited sites, matching the Stackless theme model. Keys enable updates only. The direct ZIP is served by FluentCart’s R2 storage; the clean ZIP omits the client.

The product page uses seven inline, page-owned PBB sections on `pbb-template.php`. The page keeps the existing site shell and owns its Kumo colors, Inter font, layout, and modes. No shared library blocks or unrelated products were changed. Its editable section source is retained in `docs/product-page/sections.json`.

The noindexed demo is blog 23. Its five pages and six posts use the real theme and core blocks, with original media, navigation, a sidebar, a reading example, and the canvas template. The initial default theme was Twenty Twenty-Five. The other demo sites were not activated or upgraded.

Verification includes 33 runtime checks on each of WordPress 6.7.4 and 7.1.4, updater fixtures, PHP syntax/coding standards, valid packages, Theme Check required checks, matching GitHub/R2 artifacts, and an actual WordPress bulk upgrade from 0.2.0 to 0.3.0. The package downloaded while WordPress maintenance mode was active and every installed file matched the GitHub ZIP. The synthetic verification key was then deactivated, disabled, and rotated. No customer key or order was used.

Public browser checks covered product content, checkout opening at zero price without submitting an order, matching light/dark screenshots, the native color switch, FAQs, mobile layouts, demo navigation, pagination, images, and templates. The product content had no axe A/AA violations. This is not a manual screen-reader or full plugin-compatibility certification.

For rollback, scope changes to product 1189259 and demo blog 23, and inspect fresh state first. Preserve customer download row 547 and the immutable release artifacts.
