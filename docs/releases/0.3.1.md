# Kumo Hybrid 0.3.1

Fixes native Search label wrapping and doubled inside borders, deep comment overflow, dark Calendar contrast, classic Calendar link targets, inconsistent widget headings, and ignored gallery columns. Uses a bundled MIT-licensed Tabler 3.47.0 subset from the local icon library for theme controls, Search, disclosures, RSS, and media states.

Custom block colors, sizes, and borders retain precedence. The Text palette role now uses `foreground`; legacy CSS variables and classes remain supported. No content migration is required.

The 14 regression assertions pass on WordPress 6.7.4 and 7.1.4. Runtime assertions pass 33 per version, icon assertions pass 16 per version, and seven license fixtures pass. Native comment and media interaction checks also pass. See `../validation.md` for limits.

Release delivery and live showcase evidence is recorded in `0.3.1.json`. Preserve release 0.3.0, FluentCart download row 547, and its immutable R2 artifact as the rollback target.
