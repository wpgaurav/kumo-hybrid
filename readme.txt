An independent Kumo-inspired hybrid theme with native block editor styling and the WordPress Customizer.

== Description ==
PHP templates, theme.json v3, editable core-block patterns, a responsive menu, optional widgets, and light/dark/system color modes. No required plugin, remote fonts, React frontend, or build process.

Open Appearance > Customize > Kumo design for colors, typography, layout, header action, and footer text. Use the block editor for page and post content. See README.md for full setup and usage.

== Installation ==
1. Upload the theme ZIP through Appearance > Themes > Add New > Upload Theme.
2. Activate Kumo Hybrid.
3. Set your options in the Customizer and assign your menus.
